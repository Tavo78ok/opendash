🇦🇷 OpenArgOS
"La fuerza de Debian, la calidez de nuestra tierra."
OpenArgOS es una distribución Linux basada en Debian 13 "Trixie" (Estable), diseñada para ofrecer una experiencia de usuario fluida, moderna y altamente optimizada. Combinamos la legendaria estabilidad de Debian con un entorno XFCE personalizado que hereda la elegancia de Windows 11, pero con el corazón puesto en Argentina.
🚀 Características Principales
Base Sólida: Construida sobre Debian Trixie, garantizando seguridad y soporte para hardware moderno.
Estética "Modern-Retro": Entorno XFCE configurado con Docklike y Whiskermenu, logrando una interfaz familiar (estilo Windows 11) pero sumamente ligera.
Monitor Principal: Incorpora Opendash como centro de control y monitoreo visual del sistema.
Optimización Extrema: * zRAM-tools: Compresión de memoria RAM para mejorar el multitasking en hardware con pocos recursos.
Preload: Aprendizaje de uso para una apertura de aplicaciones casi instantánea.
Kernel LTS: Máxima compatibilidad y estabilidad a largo plazo.
🖼️ Identidad Visual
Fondos de Pantalla: Una curación exclusiva de paisajes naturales de Argentina (Glaciares, Puna, Selva y Patagonia).
Wallpaper "Bloom" Federal: Un fondo principal inspirado en el diseño moderno, centrado en la "O" de OpenArgOS con tonalidades celeste y blanco.
🛠️ Especificaciones Técnicas
Arquitectura: x86_64 (64 bits).
Escritorio: XFCE 4.20 (Personalizado).
Gestor de Paquetes: APT (compatible con .deb y Flatpak).
Consumo Inicial: ~500MB - 600MB de RAM.
🇦🇷 ¿Por qué OpenArgOS?
Porque creemos que no hace falta una supercomputadora para tener un sistema hermoso y rápido. OpenArgOS está pensado para el estudiante, el trabajador y el entusiasta argentino que busca un sistema que "simplemente funcione", se vea bien y rinda al máximo.
