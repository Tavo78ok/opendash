# 🚀 Opendash v1.0 | OpenArgOs Gold Edition

Opendash es una suite de optimización y monitoreo de sistema liviana, diseñada específicamente para el ecosistema **OpenArgOs**. Permite a los usuarios de Linux controlar su hardware y software de manera centralizada con una interfaz moderna y oscura.

## ✨ Características Principales

* 📊 **Monitor de Sistema:** Seguimiento en tiempo real del uso de CPU y RAM.
* 🧹 **Limpiador:** Eliminación de archivos temporales y basura para recuperar espacio en disco.
* 🎮 **Modo Gamer:** Gestión de perfiles de energía (Ahorro, Equilibrado y Rendimiento).
* 📦 **Gestor de Apps:** Desinstalador inteligente que lista aplicaciones del sistema.
* 🌐 **Monitor de Red:** Visualización del tráfico de subida y bajada en KB/s.
